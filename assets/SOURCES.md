# Asset sources

- Fonts, embedded as subsetted base64 WOFF2 (SIL Open Font License 1.1), via the Fontsource npm packages v5.3.0:
  Barlow Condensed Bold (display), Barlow Regular (body), JetBrains Mono Regular (mono).
- Technology and GitHub icons: Simple Icons v16.35.0 (CC0 1.0), https://simpleicons.org
  (React, Next.js, Node.js, TypeScript, Firebase, MongoDB, PostgreSQL, Google Gemini, GitHub).
  Brand names and logos remain the property of their owners.
- LinkedIn: Simple Icons no longer ships the LinkedIn mark, so the connect card uses a plain "in" lettermark
  on a blue tile, not the official logo. Swap in the official mark from https://brand.linkedin.com if you want it.
- Portfolio globe icon and all other shapes: drawn by hand for this profile.
- Portrait: your GitHub photo (or a monogram placeholder until it is supplied).
